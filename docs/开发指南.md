# 开发与扩展指南

## 公共程序与本地资料

本项目按源码工作目录使用，推荐在克隆或解压后的目录执行 `pip install -e .`。公开版本只包含通用程序、规则、文档和原创示例。

`books/*.json`、`corrections/` 中的个人修正、`data/`、`output/`、本地 `tests/` 和 `reports/` 均默认忽略。个人扩展使用 `plugins/local_*.py` 或 `rules/local_*.json`，也可把规则直接写入资料配置。发布代码时请保留这些默认忽略规则。

## 模块分工

- `catalog`：本地资料配置、PDF 页数和原创示例初始化。`create_book()` 由 CLI 与面板共用。
- `presets`：递归合并通用预设与资料覆盖规则。
- `plugins`：加载内置解析器、本地插件或第三方 entry point。
- `pipeline`：应用勘误、检查题目、生成核对页面与报告。
- `export`：保留原文的 15 列 XLSX 导出、回读验证和原子保存。
- `gui`：调用相同 CLI 完成 OCR 和构建，不维护独立的解析逻辑。

## 新增资料

运行 `init-book` 或在面板点击“添加 PDF”。配置写到 `books/<资料ID>.json`，默认处理整份 PDF；先调整页码范围，再试跑一个完整章节。

配置中的 `chapters` 使用从 1 开始的 PDF 物理页码标记章节起点，例如 `{"3":"第一章 基础"}`。`first_page`、`last_page` 限定整体范围，`rules.page_ranges` 可选取包含首尾页的区间，如 `[[3,8],[15,18]]`。范围须覆盖相应题目和答案。

重复资料 ID 会被拒绝，不会覆盖现有配置。不要让不同 PDF 共用同一 OCR 缓存。

## 预设与规则覆盖

`rules/*.json` 使用 `extends` 继承预设，字典递归合并，标量和列表整体替换。循环继承或无效正则会报错。资料配置可以通过 `rules` 覆盖相同字段：

```json
{
  "rules": {
    "quiz_start": "^(?:自测题|课后习题)$",
    "sections": {"案例分析": "discuss"},
    "shared_intro_patterns": ["^请为下列"]
  }
}
```

可用小节类型为 `single/shared/multi/fill/judge/define/essay/calculate/discuss/translate/spectrum/essay_calculate`。选择题跨 A/B/X 小节连续编号时设置 `choice_numbering: "continuous"`。整节只有一道无编号题时，可用 `unnumbered_sections: {"章节名称":["essay"]}`。

`question_pattern` 和 `answer_pattern` 分别处理题干与答案的编号。调规则时关注小数续行、区间答案、共用选项、HTML 表格和跨页读序，避免无依据补写答案。

## 自定义插件

将 `plugins/example.py` 复制为 `plugins/local_custom.py`，在资料配置中设置 `"plugin":"local_custom"`：

```python
from meowcannery.parsers.rule_based import parse as parse_rules

def parse(book, rules):
    result = parse_rules(book, rules)
    # 在此处理自己资料的特殊版式，并保留原页定位。
    return result
```

插件返回 `meowcannery.plugins.ParseResult(questions, issues)`。也可通过 Python 包声明 `meowcannery.plugins` entry point。插件是本地 Python 代码，只运行自己维护或审读过的插件。

## 题目契约

必需字段为 `stem`、`type`、`options`、`answer`、`chapter`。题型为“单选题 / 多选题 / 判断题 / 填空题 / 简答题”，非选择题的 `options` 为 `[]`。选择题答案使用去重的 A–H 字母；判断答案统一为 `√` 或 `×`。

建议保留 `section`、`number`、`source`、`answer_source`、`subject`、`explanation`。`(chapter, section, number)` 必须唯一。未知题型或无法可靠匹配的内容进入 `issues`，包含 `source` 和 `reason`，尽可能附章节、小节和题号。

## 勘误

勘误位于 `corrections/<配置文件名>/`，与 `books/<配置文件名>.json` 同名。`source.json` 对 OCR 原文逐处精确替换：

```json
[{"page":"p0003.md","old":"待修正原文","new":"原页核实后的文字","reason":"PDF 第 3 页，OCR 漏字"}]
```

`questions.json` 按 `match` 唯一定位题目，并核对 `before`：

```json
[{"match":{"chapter":"第一章 基础","section":"single","number":1},
  "before":{"answer":"A"},"after":{"answer":"B"},
  "reason":"仅为格式示例，实际修正必须有原页依据"}]
```

勘误可能包含原书题目和答案，作为个人资料保留在本地。

## OCR 环境与缓存

OCR 是可选阶段。当前实现使用 `PaddleOCRVL(pipeline_version="v1.6")`，默认 150 dpi、每批 4 页。请按 [PaddleOCR 官方安装说明](https://www.paddleocr.ai/latest/en/version3.x/installation.html) 配置系统与设备支持的 PaddlePaddle，并安装提供该接口的 PaddleOCR。真实扫描识别需要单独验证设备环境。

每个资料的缓存包含 `p0001.md` 等页文件。`manifest.json` 记录 PDF SHA-256、页数、分辨率和引擎，配置不一致时拒绝复用。中断后重跑相同命令会继续缺失页。

## 导出与兼容性

格式基线保留为 Exameow 1.5.0 的原生 15 列，已验证版本为 1.4.4–1.6.1。兼容范围常量位于 `export`，CLI 环境检查和面板显示共用该信息。

`write_xlsx()` 把单元格保存为文本，处理非 BMP XML 数字实体后，再回读逐字段比较并原子替换目标文件。修改导出时应检查 emoji、生僻字、组合表情、公式样文本、前导零、长单元格和失败回滚。兼容范围不能仅按版本号或源码相似度外推。

## 本地自查

```powershell
python -m compileall -q meowcannery plugins
python -m meowcannery demo
python -m meowcannery validate "output/demo/原创入门示例_Exameow.xlsx"
```

原创示例用于验证基本流程，不能证明所有书籍版式或真实 OCR 的正确性。维护测试和报告保留在本地已忽略的目录，不把个人题库、扫描页、反馈截图或识别结果加入公共提交。
